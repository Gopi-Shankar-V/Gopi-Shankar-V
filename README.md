## `$ ls ~/projects/`

<details open>
<summary><b>⭐ ARM-Based Automotive Instrument Cluster — CAN Protocol</b> &nbsp;<code>Main Project</code></summary>
<br>

> Dual-node bare-metal automotive instrument cluster on **NXP LPC2129 (ARM7TDMI-S @ 60 MHz)**.
> Node A transmits sensor data over **CAN 2.0A at 100 kbps**. Node B drives a **16×2 HD44780 LCD** and GPIO LEDs.

- 🔧 Custom **CAN2 driver** — bit-timing, acceptance filter, **VIC-based RX ISR** from scratch (no HAL)
- ⚡ **EINT0/1/2 ISRs** for indicators & headlight + **Timer1 ISR** for 1-second ADC sampling
- 🖥️ **HD44780 LCD driver** in 4-bit mode with **CGRAM custom characters** + 250ms blink logic
- 📐 **MISRA-C** typedefs (`u8`, `u16`, `u32`) · Register-level programming (`PINSEL`, `IODIR`, `VICVect`)

`Embedded C` `LPC2129` `CAN 2.0A` `ARM7TDMI` `EINT ISR` `Timer ISR` `ADC` `VIC` `HD44780` `Keil uVision`

[![GitHub](https://img.shields.io/badge/View_Repo-0A0F0A?style=for-the-badge&logo=github&logoColor=22C55E)](https://github.com/Gopi-Shankar-V/Instrument-Cluster-Uses-CAN)

</details>

<details>
<summary><b>🔌 UART-Based Calculator on LPC2148</b></summary>
<br>

> Bare-metal arithmetic calculator on **LPC2148 (ARM7TDMI)** communicating entirely over **UART**.

- 🔧 Custom **UART0 driver** — baud rate via `U0DLL`/`U0DLM`, TX/RX polling using `U0LSR` flags
- ➕ Multi-operand parsing (`+`, `-`, `*`, `/`, `%`) with **LLONG_MAX overflow** + **divide-by-zero** guards
- 💾 Firmware compiled with **Keil uVision** → `.hex` flashed directly to ARM hardware

`Embedded C` `LPC2148` `UART` `ARM7TDMI` `Register-Level` `Keil uVision` `Bare-Metal`

[![GitHub](https://img.shields.io/badge/View_Repo-0A0F0A?style=for-the-badge&logo=github&logoColor=22C55E)](https://github.com/Gopi-Shankar-V/UART-Calculator)

</details>

<summary><b>🐧 Student DBMS — dbase Linux CLI Utility</b></summary>
<br>

> Student Database Management System in C, upgraded to a **real Linux utility** (`dbase`) installed in `/sbin`.

`C` `Linux Syscalls` `Linked List` `File I/O` `GCC` `Makefile` `CLI Utility`
